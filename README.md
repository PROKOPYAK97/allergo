# АллерГо

Презентационный MVP сканера продуктов и отчётов о проверках партий на аллергены. Интерфейс на React + TypeScript + Vite. Поиск продуктов через Open Food Facts, распознавание камерой через ZXing.

## Запуск на компьютере

Нужны Node.js 24+ и npm.

```sh
npm ci
npm run build
npm start
```

Открыть http://localhost:3000. Демо с belVita доступно на http://localhost:3000/demo. Штрихкод демо-продукта — 7622210721976.

Локальный сервер сохраняет партии и загруженные файлы в runtime-data/. Папка создаётся автоматически. Для разработки запустить сервер командой npm start и в другом терминале npm run dev. Vite откроется на http://localhost:5173 с прокси к API на порту 3000.

## Загрузка на GitHub

Распаковать архив в пустую папку и создать новый репозиторий на GitHub. Через GitHub Desktop выбрать Add local repository, затем Create a repository и Publish repository. При работе через терминал выполнить git init, git add ., git commit, затем привязать адрес собственного репозитория и выполнить git push.

В архив входят исходники, package-lock.json, сервер, API Vercel, публичные изображения и конфигурация. Зависимости устанавливаются через npm ci. Облачные данные, загруженные отчёты и привязка к аккаунту прежнего владельца в архив не входят.

## Развёртывание на своём Vercel

1. Импортировать собственный GitHub-репозиторий в Vercel.
2. Выбрать Node.js 24.x, framework Vite, build command npm run build, output directory dist. Маршруты уже заданы в vercel.json.
3. Создать приватное Vercel Blob-хранилище и подключить его к новому проекту для Production и Preview. При подключении Vercel настроит серверные переменные доступа к хранилищу. Если используется OIDC, включить его для проекта и задать BLOB_STORE_ID своего хранилища.
4. Добавить переменную VITE_STORAGE_MODE со значением blob для Production и Preview.
5. Выполнить Redeploy после настройки переменных. Новые переменные окружения применяются при следующей публикации. Открыть /demo — появится карточка belVita и закреплённый демонстрационный отчёт.

Vercel Functions в api/ сохраняют партии и материалы в Blob. Видео до 40 МБ загружаются напрямую в Blob. Ключи и токены хранятся только в переменных окружения Vercel.

## Демонстрационный сценарий

На главной странице, в меню и в сканере демо ведёт к одному продукту belVita. Для него молоко, арахис, орехи и яйцо отмечены «Не обнаружен», глютен и соя — «Присутствует в составе», остальные аллергены — «Не тестировался». Эти результаты вымышленные и явно помечены как демо.

Для остальных найденных товаров показываются демонстрационные сценарии с учётом аллергенов, заявленных в Open Food Facts. Для кодов, привязанных производителем к созданной партии, открывается отчёт этой партии. Вход в демо-кабинеты через /login.

Информация о производителе belVita содержит ссылки на официальный сайт Mondelēz и карточку товара. Поиск в Национальном каталоге доступен по внешней ссылке. API Честного знака не подключён.

## Ограничения MVP

- Демо-роли выбираются без пароля. Посетители могут изменять демонстрационные данные. Для реального пилота потребуется авторизация и разграничение прав.
- Отрицательные результаты в демо не являются реальными испытаниями и не подтверждают безопасность продукта.
- Камере на телефоне нужен HTTPS. Поиск продуктов требует подключения к интернету.
- База партий сохраняется одним JSON-документом. При одновременном редактировании действует последняя запись. Для презентации рекомендуется один редактор.
- Личные аллергены сохраняются в браузере. Обращения сохраняются в базе, внешние уведомления не подключены.
- Криптографическая подлинность Data Matrix и статус упаковки в Честном знаке не проверяются.
- Данные Open Food Facts распространяются по ODbL. Условия https://world.openfoodfacts.org/terms-of-use.

## Структура

- src/ — интерфейс, сканер, демо-отчёты, кабинеты.
- api/ — серверные функции для Vercel и Blob.
- server.mjs — локальный Node.js-сервер.
- public/ — иконки сайта.
- vercel.json — настройки публикации и маршрутизации.

## Проверки

npm run build проверяет TypeScript и собирает интерфейс. npm test запускает проверки разбора кодов и локального API.
